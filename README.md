# 🔗 URL Shortener

A simple and functional **URL Shortener** built with **Python, Flask, PostgreSQL, and SQLAlchemy**.

This project converts long URLs into short, unique URLs. The generated short URL can then be used to redirect users to the original URL.

This project was developed as **Task 1 of my CodeAlpha Internship**.

---

## 🚀 Features

- 🔗 Convert long URLs into short URLs
- 🔐 Generate unique random short codes
- 🗄️ Store URLs in PostgreSQL database
- ⚡ REST API using Flask
- 🔄 Redirect short URLs to original URLs
- 📊 Track the number of clicks
- 🕒 Store URL creation timestamp
- 🌐 Simple HTML & CSS frontend
- 🧪 API testing with Postman
- 🔧 Environment variable configuration
- 📁 Clean Flask project structure
